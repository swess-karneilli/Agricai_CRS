\# AgroAI/CRS



AI-powered agricultural decision support system.



\## Current functionality



CRS currently:



\- accepts farm coordinates

\- retrieves historical weather data

\- calculates average temperature

\- calculates rainfall

\- calculates reference evapotranspiration

\- calculates monthly rainfall



\## Current data source



Open-Meteo Historical Weather API



\## Next objective



Integrate soil information and create a complete farm environmental profile.
